튜토리얼 영상의 단계를 정리하려면 Damas로 텍스트 기록을 만들고 원본과 대조한 뒤 확인 가능한 행동을 한 줄씩 쓰세요. 사전 조건과 조건부 단계는 분리하세요. 체크리스트는 직접 작성하거나 선택적으로 검토한 텍스트를 다른 LLM에 복사해 초안을 만듭니다. Damas는 받아쓰기, 요약, 텍스트 편집과 복사를 제공합니다.

## 원본과 텍스트 준비하기

Damas는 최대 90분의 YouTube, Instagram, X 공개 주문형 동영상 링크를 지원합니다. iPhone에서는 iOS 18.6 이상, 인터넷, Premium, AI 처리 동의가 필요합니다. 처리 권한이 있는 자료만 제출하세요. 비공개, 접근 제한, 실시간 영상은 지원되지 않으며 공개 영상도 접근할 수 없으면 처리에 실패할 수 있습니다.

1. 원래 플랫폼에서 튜토리얼을 열고 링크와 제목을 메모에 보관하세요.
2. 지원되는 링크를 Damas에 입력하고 현재 앱 안내에 따라 받아쓰기를 진행하세요. AI 처리 동의를 읽으세요.
3. 처리가 끝나면 불명확한 단어, 수치, 단위를 원본 오디오와 대조한 뒤 편집하고 복사하세요.
4. 시연과 화면의 표시도 확인하세요. 말로 설명하지 않은 설정은 텍스트에 없을 수 있습니다.
5. 앱 내 요약으로 전체 흐름을 파악하되 순서와 예외는 전체 설명에서 확인하세요.

## 행동마다 확인 기준 붙이기

세 차례에 걸쳐 정리하세요. 먼저 사전 조건을 모으고, 다음으로 행동의 순서를 정하고, 마지막으로 각 행동의 완료 확인 기준을 붙입니다. 조건, 행동, 실제로 보여 주거나 말한 결과를 함께 적으세요. 결과가 없으면 ‘완료 확인 방법 언급 없음’으로 남깁니다. 조건에 따라 선택하는 두 갈래를 연속 필수 단계로 바꾸지 마세요.

‘원본 대조 완료’와 ‘내가 실행 완료’를 별도로 표시하세요. 텍스트를 확인했다고 작업까지 끝난 것은 아닙니다. 알 수 없는 설정을 상식으로 채우지 말고 보류하세요.

## 가상 예시: 스프레드시트 튜토리얼

실제 영상의 인용이 아닌 설명용 가상 예시입니다. 시트를 복제한 다음 날짜가 뒤섞였을 때만 행을 정렬하라는 튜토리얼을 가정합니다.

- 사전 조건: 원본에서 기존 시트와 날짜 열을 확인합니다.
- 행동: 시트를 복제합니다. 확인: 편집 전에 복제본이 있는지 봅니다.
- 조건부 행동: 날짜가 뒤섞였으면 복제본을 정렬하고 이미 정렬돼 있으면 건너뜁니다.
- 보류: 정렬 방향이 음성에도 화면에도 없으면 ‘최신순’이라고 추정하지 않습니다.

실제 작업에서는 영상이 뒷받침하는 확인 기준만 쓰세요. 원본에 없는 담당자, 기한, 사실이나 인용문을 만들지 마세요.

## 선택 사항: 다른 LLM에 복사할 프롬프트

다른 서비스에 공유할 권한이 있을 때만 텍스트를 복사하세요. 이 외부 초안 작성은 Damas 연동이나 자동 체크리스트 기능이 아닙니다. 예시 프롬프트:

> 아래 검토한 기록만 사용해 사전 조건, 순서가 있는 행동, 조건부 분기를 나눠 주세요. 각 행동에 근거 구절을 붙이고 완료 확인은 명시된 경우에만 적으세요. 빠진 정보는 ‘언급 없음’으로 표시하세요. 설정, 담당자, 기한, 사실, 인용문을 지어내지 마세요. 원본 대조 상태와 작업 완료 상태를 분리하세요. 출처: [링크]. 기록: [텍스트].

모든 제안을 원본 영상에서 다시 확인하세요. 시작 단계는 [받아쓰기 안내](/ko/guides/transcribe-social-video-link-iphone/), 전체 개요는 [요약 안내](/ko/guides/summarize-video-transcript-iphone/)를 참고하세요. 외국어 영상은 [번역 안내](/ko/guides/translate-social-video-iphone/)를 이용하되 기술 용어와 화면 표시를 원문과 대조하세요.

최종 체크리스트에도 원본 링크를 남기세요. 처리 시간과 정확도는 달라집니다. Damas는 미디어 다운로드, 자막 삽입, 오프라인 처리를 지원하지 않습니다. Premium도 접근할 수 없는 영상을 이용 가능하게 만들지는 않습니다.
